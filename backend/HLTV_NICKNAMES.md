## Commands

Run from `backend/`:

```powershell
.venv/Scripts/python.exe -m app.migrate_nicknames --database arena.db --dry-run --report reports/hltv-nicknames-dry-run.json
# Read the report; use its current planHash:
.venv/Scripts/python.exe -m app.migrate_nicknames --database arena.db --apply --approve-plan <planHash> --report reports/hltv-nicknames-applied.json
```

The migration refuses conflicts or a changed plan, creates and verifies a timestamped SQLite backup, checks unrelated fields before commit, and appends an audit entry to `arena.db.migrations.jsonl`. No automatic migration or seed changes are introduced. Repeating a successful migration produces zero updates. Run the nickname migration again only after intentionally reviewing a new dry-run plan.
